# AI Career Value & Learning Roadmap

A Streamlit web application powered by **Google Gemini 2.5 Flash** that takes a user's photo and career goals to generate:
- Estimated tech market compensation / freelance hourly rate.
- Professional profile presence review.
- A customized, phased learning roadmap to reach top-tier market value.
